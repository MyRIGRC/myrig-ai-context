## 4. B19 色トークン層＋編集語彙統一

### トークン命名（`--c-*` 第4系統の新設は禁止）

正典3系統（`--color-*` / `--cat-*` / `--rig-status-*`）に統合する:

```css
--color-action-primary
--color-action-primary-text
--color-action-secondary
--color-action-border

--cat-rig
--cat-parts
--cat-log

--rig-status-building
--rig-status-setting
--rig-status-active
--rig-status-stored
--rig-status-archived
```

### 手順
1. 見た目不変で `--color-action-primary: var(--cat-rig);` のように現在値を一時参照
2. 全コードを意味トークン参照へ移行（視覚回帰ゼロを検証）
3. 実機比較で A=緑 / B=中立ソリッド / C=中立アウトライン を切り替えて裁定

### 色の推奨（裁定待ち・実値変更は比較モック後）
- Primary: 黒系ソリッド（Dark時は明色ソリッド）
- Secondary: アウトライン
- Tertiary: 青いテキストリンク
- Category: 小型バッジのみ
- Status: 専用状態色
- **Bottom Nav中央「＋登録」のみ、サービスの象徴としてブランド緑を残す余地あり**（全ボタン緑と、唯一のグローバル作成ボタンだけ緑は意味が違う）

### 語彙統一
「編集」「設定」「管理」の使い分け語彙表を作成し、ボタン命名を対象明記型に揃える。
