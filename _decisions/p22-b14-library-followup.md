# ライブラリ（MyRIG CATALOG）デザイン継続課題

記録: 2026-07-27 (JST) / P22-B14 時点
経緯: ライブラリ7ページの実機確認で「**今の段階でこれでいい**（＝確定）」の裁定。
ただし下記はデザイン詰めの継続課題として分離。**モックでは触らず、PC版と揃えて決める**。

## 1. カラーチップ／色付きの縁（ブラウズ・ライブラリ共通）

- **指摘**: 「変な影、色付きの影が嫌い」。カードの色付き左縁・影の当て方が好みでない。
- **代案（イタヤ案）**: 色を影ではなく **背景に敷いて、文字を白抜き** にする方がまだよい。
- **より根本**: そもそも**色付けのカラーチップ自体が要るのか**という論点がある。
- **裁定**: とりあえず現状のまま。デザインの詰めは今後まとめて。

## 2. ライブラリの色分け・RIG/PARTSチップの要否 ★要PC裁定

- **指摘**: **ライブラリ（カタログ）については色分けは不要ではないか**。
  RIG／PARTS というチップ（バッジ）がカタログ側に要るのかも疑問。
- **理由**: カタログは「公式製品情報」の面であり、ユーザー投稿（RIG/PARTS/LOGの色分け体系）とは別物。
  同じ色分けを持ち込むと**両者の区別がつきにくくなる**。
- **裁定**: **PC版で先に確定させる論点**。モバイル側は追随する。今は現状維持。

## 3. カードの「オフィシャル感」 ★最重要

- **指摘**: ライブラリのカードが**普通のユーザー投稿カードと見分けがつかない**。
  「オフィシャル感」が出ていない。写真の質もあるが、それだけではない。
- **背景**: ライブラリは**マネタイズの要**（購入導線・アフィリエイト）。ここの信頼感が効く。
- **検討の方向（未裁定）**: 白背景の物撮り前提のカード型、枠線・角丸・余白の別系統化、
  メーカーロゴの扱い、スペックの露出、写真がない場合の IMAGE PENDING の見せ方 など。
- **裁定**: 現状は暫定。今後デザインを詰める。

## 4. パーツカタログの絞り込みスケール問題 ★アイデアが必要

- **指摘**: パーツは**何十万点**規模になる。現在の「メーカー検索＋カテゴリ＋用途＋STATUS」では足りない。
  どう絞り込ませるかは**難しく、アイデアが要る**論点。
- **現状（P22-B12）**: PC左サイドバーの4群をシートへ写像しただけ。件数スケールは未考慮。
- **未検討の切り口（メモ）**: 車種／シャーシからの逆引き、互換性（対応機種）起点、
  サイズ・規格（1.9"/12mm hex 等）のファセット、型番直接入力、絞り込み結果件数のリアルタイム表示、
  段階的な絞り込み（大分類→中分類）など。
- **裁定**: 現時点では保留。設計として別途詰める。
