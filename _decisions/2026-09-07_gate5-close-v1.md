## 誤読しないこと

**DECISION 2 / 3 は「揃えない」という裁定であって、DECISION 4 を緩める根拠にしない。**

- 揃えないのは **見た目・役割** — RIG / PARTS / LOG は用途が違うので、片方の意匠を機械的に他方へ波及させない
- 揃えるのは **同一責務の state / behavior / aria** — `action identity` / `pressed state` / `count` /
  `aria-pressed` / `toggle behavior` / `rollback・error 時の扱い` は 1 か所で実装する
- `<dt-actions>` の rail / inline は**表示 variant** として分けてよい。契約は同じ

**DECISION 1 の運用:** `data-lightbox` 属性は将来フックとして残すが、
`cursor:zoom-in` や hover の明度変化は出さない。未実装の機能を UI で約束しないため。
