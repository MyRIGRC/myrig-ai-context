# DECISION — Feed のタブ構成を「おすすめ / 新着 / フォロー中」の3本に（#28 の2タブは失効）

- 日付: 2026-09-07 JST
- revision: MYRIG-20260907-071
- 失効させるもの: **#28裁定（2026-07-23 イタヤ実機裁定）**「おすすめ / フォロー中の2タブ。全投稿時系列は置かない」
- 更新する正典: `docs/ui/page-role-matrix-v1.md` §6 / §2 サイトマップ / Page Matrix / ロードマップ表

---

## 裁定

**Feed のタブは「おすすめ / 新着 / フォロー中」の3本とする。**

| タブ | 何を基準に並ぶか |
|---|---|
| おすすめ | **興味・発見ベース** |
| 新着 | **全公開 LOG の純時系列**（推薦・人気による加工をしない） |
| フォロー中 | **social graph ベース** |

---

## 🔴 変えた理由（ここを誤読しないこと）

**「現行実装が3タブだから正典を合わせた」のではない。**

Feed / LOG Detail continuity（068 / 069）を詰めた結果、
**Feed は Browse や Library の派生ではなく、Feed 単体で目的を完結できるトップレベル体験である**
という設計原則が明確になった（`_decisions/2026-09-07_toplevel-surfaces-v1.md`）。
**Feed の独立性を再検討した結果として裁定を更新した。**

その前提に立つと、3つのタブは役割が明確に分かれる。

さらに、**MVP の「おすすめ」は完全な推薦アルゴリズムではない**
（正典 §6 でも「新着＋人気の擬似ミックスで可」としている）。
推薦が未成熟な間、**加工されていない全公開 LOG の時系列入口を残す価値がある。**

#28 が退けた「すべて（全投稿時系列）」は **X 型の拡散導線**としての話であり、
本裁定の「新着」は **推薦が未成熟な間の素の入口**という別の役割で置く。
🔴 おすすめが本格的な推薦になっても、**「素の時系列を見る入口」として新着は残す。**

---

## 実装との関係

**実装変更は無い。** PC 正本 `myrig-feed-v3.html` と Mobile `feed.html` は
以前から3タブで実装されており、今回**正典側を実装に合わせて更新した**のではなく、
**再検討の結果として到達した形が、たまたま実装と一致していた。**

- PC: `data-feed-panel="all|latest|following"`（おすすめ / 新着 / フォロー中）
- Mobile: `data-tab="reco|latest|following"`（同じ3本・同じ順序・同じ日本語ラベル）
- おすすめの並びは PC / Mobile とも「新着＋人気の擬似ミックス」で一致

これにより、`page-role-matrix-v1.md` の
「⚠️ PC正本は未適用（3タブのまま）なので参照実装にしない」という注記は不要になり、削除した。

## 影響

- Feed に含めないもの（Repost / 引用 / DM / RIG・PARTS カード混在 / ランキング）は**変更なし**
- 画像表示・追加ロード（#28 / #25）の記述も**変更なし**
