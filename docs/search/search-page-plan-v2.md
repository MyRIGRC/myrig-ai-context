## 検索結果

- **SearchHeader**（戻る = fallback `/search`）
- **種別6本・件数つき**（すべて/RIG/パーツ/LOG/製品情報/ユーザー）。実装は `.filter-chip` のチップ列
- **絞り込みSheet** ＋ 件数バッジ ＋ 適用中条件チップ

### ソート（2026-08-21 裁定⑦⑧）

| 面 | 挙動 |
|---|---|
| 「すべて」タブ | **ソート行を出さない**（横断ソートは定義不能） |
| 種別タブ | 単一ドロップダウン |

**「人気順」は使わない。** 何で並んでいるかを名指しする。

| 種別 | 選択肢 |
|---|---|
| RIG | 関連順 / 新着順 / いいね順 |
| パーツ | 関連順 / 装着例が多い順 / 新着順 |
| LOG | 関連順 / 新着順 / いいね順 |
| 製品情報 | 関連順 / 登録RIGが多い順 / 新着順 |
| ユーザー | 関連順 / RIG登録数順 |

既定は全種別「関連順」。

### 「すべて」= ダイジェスト29件

RIG8 / パーツ8 / 製品4 / LOG6 / ユーザー3。表示順は rig → parts → lib → log → user。
各セクションに「◯◯の結果をすべて見る →」。**無限にしない**（概観の役割）。

### 種別タブ = 無限スクロール

6件ずつ追加。ページ送りUIは無い。
6件に1枚の**フルワイド注目枠**（FEATURED・検索結果とは別枠）。**ユーザータブには差し込まない**。

### 表示形式

RIG / パーツ / 製品情報 = 2列グリッド。LOG / ユーザー = リスト行。空状態 = `.m-empty`。

### 広告

**検索面は広告ゼロ**（2026-08-21 裁定①）。

## スコープ定義

実装 `search-results.html` の定数群が一元定義。

| 定数 | 内容 |
|---|---|
| `LABEL` | RIG / パーツ / LOG / 製品情報 / ユーザー |
| `UNIT` | 台 / 点 / 件 / 件 / 人 |
| `GRIDTYPE` | rig, parts, lib = グリッド |
| `DIGEST` | rig8, parts8, lib4, log6, user3 |
| `SORT_OPTIONS` / `SORT_DEFAULT` | 上記のとおり |

**プレースホルダ基準文言: `RIG・パーツ・LOG・製品情報を検索`**
モバイルは探し方でスコープ連動（型番 → `型番・製品番号を入力（例: TRX-4）`、
ユーザー → `ユーザー名・ガレージ名を検索`）。
