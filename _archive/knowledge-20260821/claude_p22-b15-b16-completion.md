### 処遇の要点
- **PCの左サイドバー・タブ列 → セグメント切替**（設定5面・ヘルプ4面・法務3面・エラー6種）
- **認証 / オンボーディング / ツアー / エラーは Bottom Nav なし** — アプリシェル外の状態として扱う
- **PC footer は drop(G2)** — ユーザーメニュー内「情報」ブロックへ集約済み
- **法務の [DRAFT] 警告と placeholder 表記は削らず carry**（公式根拠 > 推測。勝手に本番文言化しない）

### 是正3件（再発防止メモ）
1. **縦フレックスでバーが潰れる** — `#mobileViewport` は `display:flex; flex-direction:column`。本文が `flex:none` のため、`flex` 未指定のセグメント帯が **64px→17px に縮み、中のチップが16pxにクリップ**されていた。`flex: 0 0 auto` を明示。**shell 直下に新しいバー類を足すときは必ず `flex:0 0 auto` を付ける。**
2. **sticky ヘッダー直下は ::after 拡張が効かない** — 上側をヘッダーに奪われる。実寸48pxで確保する（B3の「浮遊ボタンが画面上端で切られる」と同型）。
3. **本文中のインラインリンクは行ボックス24pxしかない** — 48px拡張どうしが隣接して奪い合う。独立行に出す。

### 検証ゲート自体の是正
ダークモード判定を「**前景輝度**」から「**前景と実背景のコントラスト比 3.0 以上**」へ改めた。
従来は反転チップ（暗文字×明背景）を誤検出しており、本物の問題を隠すノイズになっていた。

## 2. B16: PC⇄モバイル 見比べビュー

イタヤ要望「同じページ内にPC版とモバイル版のリンクを作って、両方を見比べながらデザインチェック・最終チェックができるようにしたい」への対応。

- **PC正典一式（39ページ＋css/img/assets、約17MB）を `mockup-deploy/pc/` へ同梱**。モバイルモックと同じデプロイ・同じURLから配信する。
- **`compare.html`** — 左PC・右モバイルの2ペイン。41対を収録。
  - ページ送り: セレクト（グループ6分類つき）／前後ボタン／←→キー
  - 表示モード: 見比べ / PCのみ / モバイルのみ
  - PC幅 1024 / 1280 / 1440、モバイル幅 360 / 390 / 440
  - PCは**実幅で描画してから `transform: scale()` で縮小**するので、レイアウトを崩さず全体像を見られる
  - `compare.html?m=<モバイルファイル名>` でその対を直接開ける
- **ランチャーに表示モード切替**（モバイル / 見比べ / PC版）。カード55枚すべてに `data-pc` を持たせ、モードに応じて**遷移先だけ**を差し替える。既存のグループ構成・確定/新規表示は不変。選択は localStorage に記憶。

### 運用メモ
PC正典を更新したら `pc/` へコピーし直す必要がある（現在は手動同期）。
同期を忘れると比較対象が古いままになるため、PC側を触ったバッチでは `pc/` の更新も同じバッチに含める。
