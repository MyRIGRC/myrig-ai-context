## 1. 着手前に実測した前提（重要）

P22-C18 で「モバイル42ページが v8 未適用」と記録していたが、実態はもう一段深かった。

- モバイルは **`--cat-rig` をどこにも定義していなかった**。全参照が `var(--cat-rig, #66b900)` の

  **検索ボタンも登録ボタンもフォローボタンも黄色になる**。
  `color-token-decision-v8.md` §4 の警告そのものが現実に存在していた。

  内訳は「種別バッジ」だけでなく、**操作ボタン・アバター・OWNERバッジ・件数バッジ**が大半だった。

## 2. やったこと

### ① 職域分離（B19手順② / 値は変えず＝視覚回帰ゼロ）

共有CSS **74ルール**＋ページ内スタイル **264ルール** を、用途別の意味トークンへ移した。

| 用途 | トークン | 初期値（現行のまま） |
|---|---|---|
| 操作 | `--color-action-primary` / `--color-action-primary-text` | 緑 `#66b900`（dark `#7acc1e`）/ 白 |
| 現在地・選択・フォーカス | `--color-selected` / `-b` / `-c` | 緑 / 紫 / 橙 |
| アバターのプレースホルダ | `--color-avatar-bg` / `-b` / `-c` / `--color-avatar-text` | 緑 / 紫 / 橙 / 白 |
| 通知・新着・件数・OWNER 等 | `--color-notice-a` / `-b` / `-c` | 緑 / 紫 / 橙 |

**通知系を1色に畳まなかったのは意図的**。元の色をそのまま持たせないと視覚回帰が出るため、
「まず参照を外す」ことだけを行い、値を揃えるかどうかは後続の判断に残した。

**検証:** 41ページ×light の計算色スナップショット差分は **13件**。
うち 7件は `index-e-roomclip.html` がページ内で v8 を先行定義していたための**意図した脱・継承**
（NEWバッジと Bottom Nav ピルがカテゴリ色を継いでいた）、残り 6件は測定ノイズ
（同一コードを2回測っても light で6件、dark では632件出る＝**darkのスナップショット比較は使えない**）。

### ② v8 の定義（B19手順③の前半）

```css
:root { --cat-rig:#FBFF00; --cat-rig-on:#151515;
        --cat-parts:#D92D20; --cat-parts-on:#ffffff;
        --cat-log:#2F5F8F; --cat-log-on:#ffffff; }
[data-theme="dark"] { --cat-log:#3F709E; }
```

フォールバック値 **200箇所**も v8 へ更新した。

### ③ 塗りバッジの文字色

「親ルールが `color:#fff` を持ち、修飾子（`--rig` 等）は `background` しか持たない」形が多く、
機械的な同一ルール内置換では届かなかった。修飾子側に対トークンを足して **+59箇所**を解消。
あわせて、JS がインラインで書いていたコメントアバターの `color:#fff`（`avc` データも
カテゴリ色参照だった）と、登録チップの「＋」の `color:#fff` も是正した。

### ④ チップの文法を2種類に整理

RIG のレモンイエローは **文字色・線色としては成立しない**（白地で 1.08）。
一方で、押して切り替えるチップを既定で塗ると「もう選ばれている」ように見える。そこで分けた。

- **静的な種別ラベル**（`.lb-chip--X` / `.cat-badge--X` / `.gcard__type--X` / `.bp-catsub--X` /
  `.feed-card__type` …）= **塗り**（地＝カテゴリ色・文字＝対トークン）
- **押して切り替えるチップ**（`.type-chip--X` / `.search-chip--X`）=
  **OFF は中立の線＋種別色の 8px ドット / ON は塗り**

PARTS赤・LOG紺もダークで 3.85〜4.03 と基準割れだったので、3種まとめて是正した。
ドットの文法は既存の `.cat-chip__dot--X` と同じで、新しい表現を増やしていない。

## 4. 未裁定 — 操作の色（B19手順③の後半）

`--color-action-primary` は**まだ緑のまま**。比較ページを作った。

**`mockup-deploy/_compare/action-color-abc.html`**（ライト／ダーク切替つき）

| 案 | 内容 | 論点 |
|---|---|---|
| **A** | 現行の緑を残す | v8以前から続く見え方。画面のどこかに必ず緑がある |
| **B** | 中立ソリッド（ライト=黒 / ダーク=白） | 色が付くのは種別バッジだけになり、黄・赤・紺が種別の記号として読める |
| **C** | 中立アウトライン | いちばん静か。ただし主操作（登録・検索）の強さが落ちる |

外部レビュー §4 の但し書き「**Bottom Nav 中央の『＋登録』のみ、サービスの象徴としてブランド色を残す余地あり**」
（全ボタンが緑なのと、唯一のグローバル作成ボタンだけ緑なのは意味が違う）は、B/C とも併用できる。

**Claude の推奨は B＋『＋登録』のみブランド色。** 理由は、v8 の狙いが「カテゴリ色に種別の意味を戻すこと」
であり、操作が有彩色のままだと黄・赤・紺が背景に埋もれる。ただし全部を中立にすると
MyRIG らしさの手がかりが消えるので、象徴を1点だけ残す。
