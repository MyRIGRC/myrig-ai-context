## 1. ユーザー（/admin/users・/admin/users/:id）— A

### 一覧（探す）
- 検索: username・表示名・**メールアドレス（完全一致だけ）**・登録日の範囲
- 絞り込み: 状態（利用中 / 停止中 / 退会の猶予中 / 確定済み / 登録途中）・案件あり・保全あり
- 列: username・表示名・状態・登録日・投稿数・開いている案件の数
- メールアドレスは一覧に出さない（詳細で、押したときだけ出す。出したことを Audit に残す）

### 詳細（全体像・v0.2 U6）
```
┌ 見出し: @username ・ 状態 ・ 登録日 ・ 同意した規約の版
├ 左（見る）                           ├ 右（決める）
│ プロフィール（アバター・表示名・自己紹介）│ 停止 / 解除（理由の条・期限・公開中も隠すか）
│ 投稿: RIG / PARTS / LOG / コメント     │ プロフィールの処置（項目ごとに既定へ戻す）
│   （運営の非表示も見える・各投稿へ）    │ 一括の処置（スパム: 停止 ＋ 持ち主の門で全部隠す）
│ 案件: 受けた通報・送ったお問い合わせ・  │ 保全をかける（範囲を選ぶ）
│   過去の処置                           │ 書き出し（本人確認の済んだ案件からだけ・HOLD 中は押せない）
│ ログイン方法・最後のログイン            │ 内部メモ
│ この人への操作の記録                    │
```
- **運営者のアカウントは、停止・退会の処置の対象にならない**（ボタンを出さない・v1.2 M5）
- 一括の処置は**戻せる**（「一括で戻す」が同じ画面にある）

## 2. 投稿の管理（/admin/content）— A（注目・一括は B）

- 種類のタブ: RIG / PARTS / LOG / コメント
- 検索: 題名・本文の言葉・username・**URL を貼る**（v1.3 Q-S1）
- 絞り込み: 状態（公開 / 利用者が非公開 / **運営の非表示** / 削除）・カテゴリ・期間・通報あり
- 一覧: 縮小画像 1 枚・題名・投稿者・日時・状態・通報の数
- 詳細: **利用者の画面と同じ見た目のプレビュー**（運営の非表示でも見える）＋ 右に操作
  - 非表示 / 戻す（理由の条・通知の文）
  - カテゴリの誤り → **本人に直してほしいと知らせる**（運営が勝手に書き換えない）
  - 注目に選ぶ（B・Page Composer の manual_pick へ）
- 画像 1 枚だけの問題は、MVP では投稿ごと一時非表示（v0.2 M9）

## 3. データ（/admin/data）— A

3 つのタブ。どれも「消える予定のもの」と「止まっているもの」を見る場所。

| タブ | 中身 |
|---|---|
| **退会** | 猶予中（あと何日）・確定処理の待ち・処理中・**止まったもの（やり直す）**・確定済み。保全のかかったデータは「この部分は消去されません（保全 #12）」と出る |
| **保存期間** | 次の 30 日に期限が来るもの（種類ごとの件数）・前回の処理の結果。**本文の伏せ字の確認が要るもの**だけ一覧で出す |
| **保全** | かかっている保全の一覧（範囲・理由・見直しの日）。**見直しの日が過ぎたもの**を上に。外すときは理由・もう一度の本人確認・Audit。外した時点で期間を過ぎていれば、すぐ消すことを表示してから実行 |

- 書き出し（D4）は、ユーザーの詳細か案件の詳細から始める（ここには一覧だけ: 作った日・期限・ダウンロードされたか）。ダウンロードの URL は期限つき

## 4. お知らせ（/admin/publishing）— A

- 一覧: 下書き / 予約 / 公開中 / 終わった。種類（メンテナンス・障害・規約・新機能・お知らせ）
- 作る画面: 種類・題名・本文（決まった書式だけ・HTML 不可）・画像（3 枚まで）・ボタン（文と行き先）・**重要にするか**（重要は設定で止められない・確認を 1 つ挟む）・公開の日時・終わりの日時
- **プレビュー**: /news と通知一覧での見え方
- 文のひな形（理由の通知・照会・受付の自動返信）もここで管理（v0.3 Publishing）
- Home の 1 行（B）は、ここに「Home に出す」の項目を後で足す（G18 を Home レーンで裁定してから）

## 5. 購入先（/admin/commerce）— A（業務 K0・v1.2 S6）

| タブ | 中身 |
|---|---|
| **お店** | 名前・提携の種類（affiliate / direct / official）・**提携の状態（申請中 / 有効 / 停止）**・国。状態を変えると、そのお店の購入先が一斉に出る / 消える（変える前に「N 件が表示されます / 消えます」と出す） |
| **購入先** | Master（RIG / パーツ・バリアント）を Catalog の名前で探す → お店・国・URL・優先度・有効 / 無効。**表示されるか**（提携有効 かつ 購入先有効 かつ リンク ok）を行ごとに「表示中 / 出ない（理由）」で出す |
| **リンクの確認** | 切れたもの・確認できなかったものの一覧 → 直す / 止める。確認は定期の Job（v1.0 admin_jobs） |

- PR の表示は部品が必ず出す。この画面に「PR を消す」設定は無い（v1.1）
- Master の名前は Catalog（Research）から読むだけ。ここで Master は直さない

## 6. 処理と費用（/admin/system）— A（見るだけ）

- **処理**: 種類ごとの最後の実行・成功 / 失敗・止まったもの（やり直す）。退会の確定・保存期間・メール・リンクの確認・同期
- **費用と上限**: 各サービスの使用の割合（50 / 75 / 100% の通知を受けたもの）・Auth の MAU。**縮退モードの今の段階**を表示（切り替えは外の手順・v1.0 原則 10。切り替えの画面は B）
- **外の手順へのリンク**: 緊急時の止め方・管理者の締め出しからの復旧（手順書）
- **非常ベル**: 鳴らした記録（送信の状態・確認した時刻）
